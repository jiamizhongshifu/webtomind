# WebToMind Skill 商店改版与付费供给扩展

日期：2026-10-21。状态：本地实现与候选包验收；未发布、未启用新商品收款。

## 产品选择

核心定位：为内容创作者和小团队提供可安装、可编辑、可复用的创作工作流。先展示实际产出，再说明输入、依赖、许可和价格，最后安装到用户的 Agent。

付费理由是完整任务交付：叙事结构、可编辑模板、执行脚本、样例与检查说明。免费 Skill 提供完整的小任务体验，不能用残缺输出作为付费诱导。图片生成、提示词和充值保留旧路径，移入“更多工具”，不再占据主导航或首页主诉求。

## 竞品核查与采用边界

2026-10-21 查看公开页面与 Chrome 首屏，未购买 Premium、未获取私有包、未验证竞品宣传的用户数或安装质量。

| 观察 | 对 WebToMind 的落实 |

| [YouMind Skills](https://youmind.com/zh-CN/skills) 以编辑精选、创作者和任务卡片建立内容发现；榜单有免费/付费切换 | 保留任务搜索、付费筛选和精选；现阶段不伪造创作者生态、排名、销量或评分 |
| Skillry 销售全库访问；YouMind 同时强调创作者供给与安装奖励 | 先经营自有精选库；第三方入驻、抽成、结算不是本轮已完成能力；不把积分奖励等同现金分成 |

这是对公开产品组织方式的分析，不复刻竞品包内容、案例素材、品牌或付费课程。Skillry 的既有价格研究见 [研究记录](SKILLRY_RESEARCH_2026-10-20.md)。我们的合同边界见 [会员策略](SKILL_MEMBERSHIP_AND_SALES_STRATEGY.md)。本轮不新增 Lifetime 承诺，也不变更历史购买权益。

上述价格是后续测试假设，不是线上售价。创建可售 SKU 前需要按商品 slug 关联真实交付包、价格币种与单品权益；只有通过付款、退款和下载全链路验收才启用。原 `xhs-carousel` 继续保留已准备的单品策略。四个候选与它合计五个付费交付候选。

会员价值：单品适合明确的一次任务，会员适合持续跨类型创作；详情页明确“买断当前单品及运营期间更新”与“有效期内访问纳入会员的库”的区别。模型/API 费用另计。不能在仍为待审的阶段把这四个候选显示成已包含且可下载。

## 网站结构与本轮实现

- 首页：任务价值 → 自有产出预览 → 搜索 → 四类交付入口 → 付费精选 → 免费体验 → 使用步骤 → 可展开安装说明 → 会员 → FAQ。
- 主导航：发现 Skill、免费 Skill、会员与价格。图片创作台、提示词、充值归入“更多工具”；移动端有可展开菜单与 Escape 关闭。
- 目录：搜索、类型、免费/付费、排序；价格和购买以服务端有效商品为准，不硬编码虚假的可售价格。
- 详情：升级为大视频预览、缩略图与商品双栏结构，继续使用既有购买卡、单品/会员权益和安装流程。视频卡片及详情页的本轮补充见 [实现与媒体记录](SKILL_VIDEO_STOREFRONT_2026-10-21.md)。
- SEO：首页改为创作 Skill 商店；CollectionPage 不再把整个站点描述成免费图片生成软件。
- 旧图片/提示词 URL 保持，避免现有用户和搜索入口失效。
- 未加载目录时明确报错并提供目录重试；空库显示筹备状态，不用虚构商品填充生产页面。

## 数据与验收边界

商品目录仍读取真实 API。本地浏览器验收以模拟 API 提供候选卡片，测试 UI 行为，不写数据库或触发支付。新预览图片来源于本机原创、脱敏演示输出；付费模板与归档保留在私有内容库，公共应用仓库仅包含公开预览。

发布仍须遵守 `PRODUCTION_RELEASE.md`：处理现有 Skill 数据表、私有交付存储、CLI 发布与支付验收，以及 hosted overlay 的源哈希一致性。此文档不构成已部署或可销售的证明。
