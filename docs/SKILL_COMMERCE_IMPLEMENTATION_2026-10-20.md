| 单品购买 | 只购买指定 Skill；服务端固定价格与商品版本/哈希/合同快照；未发布或无可交付版本的商品不可结账 |

## 启用销售前的验收

1. **商品就绪。** 免费五项和首个付费商品逐包核对脱敏、作者/上游权利、完整许可、依赖成本、干净 Agent 安装及真实输入输出。订阅启用前至少五个付费商品可售。`LicenseRef-WebToMind-Proprietary` 标签不能代替实际许可文件；页面中的本地继续使用、更新与商用边界必须同步进入交付包。
2. **历史合同核查。** 在受控环境只读核对现有 `skill_pro`、Pro/Max、Lifetime 的订单/订阅/权益汇总及异常；本轮没有查询生产数据，不应假设历史订单为空。不得把用户标识、付款详情或凭证写进公开仓库。
3. **迁移与部署。** 按 `PRODUCTION_RELEASE.md` 执行，先在受控预发布环境迁移并保持商品关闭，再部署兼容 API 和界面。生产托管内容 overlay 如有哈希冲突，审阅并更新 overlay，不能关闭完整性保护。
4. **支付验收。** 分别验证 Stripe 单品、订阅首购、续费、取消、到期、退款、重复/乱序 webhook；验证支付宝预付购买、通知重试、到期和人工退款处理。核对付款金额、币种、订单快照与实际访问，创作台原有积分和订阅应保持独立。
5. **下载验收。** 用真实订单验证网站和 CLI 下载、其他账号拒绝访问、同账号多来源权益、退款后受限、到期后更新受限。真实商品安装、成品质量和生产下载尚未由本轮 UI 数据夹具证明。
6. **逐项启用。** 对已经验收的具体商品启用 `is_active`，发布一致的价格/合同/支持边界，再完成生产桌面和移动端验收。不能批量打开尚无交付物的商品。

## 回退与后续

出现问题先关闭相应新商品的 `is_active`，停止新销售；保留既有订单、订阅、支付回调与售后处理。停止新销售不会自动取消既有自动续费订阅；涉及续费调整须单独核对范围并执行。不要删除交易表或批量撤销旧用户权益作为回退手段。

本轮未实施固定套装、差价抵扣、Founding Lifetime 名额管理、每日下载限额、分销、第三方卖家分账。上述仍按策略中的 P2/后续阶段推进，不得在页面写成已提供权益。

宣传片继续采用英文、16:9、无口播的功能演示；现有视频不替代商品许可或安装验收。
