# NotebookLM Video

SiSkill's independent `notebooklm-video` package prepares a source ledger, supported
story beats, producer notes and a review page, then guides generation and download
in the buyer's own Google Gemini Notebook (NotebookLM) account. It is an external
service workflow, not an offline video renderer or an official Google integration.

Target release: 1.0.0, US$9.99 individually and included in SiSkill Pro. Google account
access, generation quota and fees are separate. Supported formats and advanced
features depend on account eligibility; no exact duration, shots or resolution is
promised. Native generated videos may include narration; the store demo is silent.

## Provenance and distribution

The instructions, local Node helpers, review layout and fictional editorial source
are original. The referenced [post](https://x.com/dotey/status/2112439331000328354)
informed workflow design; its prompt and internal tool names are not repackaged.
Current service behavior was checked against [Google's instructions](https://support.google.com/gemininotebook/answer/16454555)
and the authenticated browser. An unofficial API client is neither bundled nor required.

The private source and acceptance evidence are retained outside public Git. The
package follows the `external-service-browser-workflow` profile. Existing offline
renderer validation is unchanged. Local scripts never upload, install software or
access authentication; uploads occur through the buyer's reviewed browser workflow.

Published metadata contains only archive identity and sanitized examples. Private
notebook IDs, provider URLs, account details, full acceptance records and the paid
implementation must not enter public assets. The private R2 object is immutable and
hash-checked after upload. Downloads use existing sign-in and purchase/Pro checks.

## Acceptance scope

Local preparation checks cover source IDs, exact supporting extracts, upload consent,
credential patterns, existing-output preservation and HTML escaping. These do not
prove factual accuracy. Extracted installation checks cover Codex and Claude folder
layouts, not autonomous discovery in every Agent.

A real browser generation, downloaded MP4, decode inspection and reviewed frames are
required before activating the SKU. A preparation page or animated illustration is
not a generated-video result. The public demo labels workflow illustration separately
from actual generated output. Checkout acceptance creates and expires an unpaid
session; no real card charge is needed to add a SKU to the existing payment pipeline.

## Reviewed example

The real run produced a 397.642-second, 1280×720 H.264 video. Full decode passed;
representative frames and a local ASR transcript were checked. Google chose green
artwork despite a terracotta request, and the narration contained an unsupported
“guarantees” claim about the source ledger. The original remains private. Published
examples use a reviewed 12-second silent excerpt, with the provider watermark retained.
The package includes this review finding; voice listening quality is not claimed.

The 24-second English storefront demonstration is a separate original huashu-motion
animation. It has no audio and labels the reconstructed browser handoff. Private
archive 1.0.0 contains 15 files, passes privacy scanning and reproducible packaging,
and runs after extraction into both Codex and Claude folder layouts. These checks do
not claim a second cloud run or automatic discovery in Claude.
