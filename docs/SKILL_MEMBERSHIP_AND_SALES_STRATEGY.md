# WebToMind 会员权益与 Skill 销售策略

更新：2026-10-20 · 状态：本地商业方案 v2，待实现与上线验收；不是已生效的价格、合同或用户权益。

研究依据：[Skillry 深度调研](SKILLRY_RESEARCH_2026-10-20.md)。本文件替代同日转型盘点中概括性的会员/销售建议；历史核验记录保留。

## 1. 产品定位

**面向创作者、小商家和独立开发者，销售经过验证、可在用户 Agent 内重复使用的商业内容工作流。**

首期为 WebToMind 自营精选库。前台按任务组织：社媒内容、门店上新、品牌发布、电商素材；图片、视频、网页、幻灯片是筛选维度。后续开放第三方卖家时单设 Marketplace，不能把新卖家商品自动塞进已售“自营全库”的终身承诺。

英文展示与无口播 16:9 功能演示继续作为默认宣传标准；商品是否支持英文按实际测试标记，不能因宣传片英文就扩大兼容承诺。

补充约定：

- “运营期间”不能被写成永久在线保证；已下载版本允许继续使用，但不保证未来所有操作系统、Agent 和模型都兼容。
- 本地无按次限制不代表云端无限下载，也不代表每次生成结果一致。
- 客户可获得成品与允许交付的项目源文件，不获得原始可复用付费 Skill 包或账号。包内第三方开源部分继续按其自身许可，不能被自有条款收回已有权利。
- 组织多人共享需要后续 Team 许可；首期不出售尚未实现的团队席位。
- 订阅到期不撤回正常生成的成品，不远程删除本地文件；停止新的 Premium 下载/更新。退款或欺诈撤销按对应订单处理，不能误伤独立单品或其他有效权益。
- 不承诺永久留存被下架的第三方素材；重大安全或权利问题可暂停受影响包，并说明可用替代、修复或退款处理。

## 4. 创作台积分与旧会员保护

当前代码中的 `skill_pro` 复制旧 Pro 的月度积分和限制，而售价约为旧 Pro 本地回退价的一半。**新售内容会员应与算力方案分离。**

执行原则：

1. 先核对生产是否已出现 `skill_pro` 订单或订阅。本次未查询生产，不假设没有用户。
2. 旧 Pro/Max 的积分、工具与有效期继续按原购买合同履约；其有效期内附带自营 Pro Skill，不要求重复付款。
3. 若已有售出的 Skill Pro 含积分，也保留已购权益。使用明确的新套餐版本/价格对象销售不含积分的内容会员，禁止覆盖历史订单。
4. 新的 Skill 内容订阅与创作台订阅可并存，但同一用户不应被引导重复购买已拥有的内容访问。套餐管理展示当前来源、有效期与缺少的权益。
5. 不能只将 `monthly_credits` 改为 0。现有订阅逻辑会用月度配额替换免费每日额度；必须拆分内容访问和算力归属，避免买 Skill 后免费创作台额度被意外清空。
6. 年付内容会员不预发一年算力；终身也不承诺长期免费生图/视频。独立积分包按已有有效期规则处理。

当前“同 Pro 创作台积分”的页面文案是现有实现状态；待新的 SKU、权益模型与验证完成后再整体替换。本次不通过改文案假装后台已完成拆分。

## 5. 终身会员的边界与开放条件

保留 $169/¥899 的创始价格作为备选，不在首期自动开放。它相当于约 2.14 个美元年费或 2.25 个人民币年费，是提前收取未来内容和维护收入，不能用来承担不限量算力。

建议首批最多 100 席，只有服务端可原子计数、支付占位到期可释放、退款后名额规则确定时才显示剩余席位。未实现前不放倒计时或虚假稀缺文案。

开放条件：

- 首发至少 5 个付费 Skill 完成输入、独立安装、真实输出、成本说明、脱敏与许可验收。
- 月/年与单品的成功付款、撤销、到期、更新和重下载已做端到端验证。
- 至少完成连续两个四周的维护周期，记录支持工时与兼容修复成本。
- 已核算留给维护与支持的收入，明确“WebToMind 自营 Pro 库”范围；第三方商店、团队版、定制服务和云算力单列。
- 购买 Lifetime 前展示仍在续费的订阅；提供明确的停止后续续费入口与结果，不能让用户误以为买断自动取消了旧账单。

若上述条件不成立，只开放免费与已验收单品，不提前收全年/终身款弥补内容不足。

## 6. 免费与付费商品策略

### 免费五项

小红书封面、OG 分享图、周报幻灯片、候补预约页、文字动效视频。每个都能完成一个任务、输出可用文件、无强制水印，展示示例输入与运行条件。

免费商品用于建立信任，不要求“缺少最后一步才能付费”。商品页关联一个下一步任务，例如“完成封面 → 需要整组图文 → 轮播工作流”。

### 付费优先级

| 优先级 | 商品 | 付费价值 | 当前缺口 |
| --- | --- | --- | --- |
| 1 | 小红书图文轮播 `xhs-carousel` | 多页内容结构、统一排版、可编辑与批量导出 | 已有当前会话案例；补独立安装与所售语言验收 |
| 2 | 电商主图五件套 `ecommerce-main-image` | 同一产品的卖点、细节、场景多图 | 用真实授权商品照片替换占位演示，修复已知布局问题 |
| 3 | 门店上新营销工作流 | 同一活动的多尺寸、渠道适配与一致性 | 从本机工作流提炼独立包与授权明确的案例 |
| 4 | 品牌发布视觉提案 | 情绪板、方案与输出规范形成完整交付 | 新独立包、资料需求与验收标准 |
| 5 | 系列写真工作流 | 多张一致性、选片、编辑与交付 | 原创/获授权人物素材，模型成本与一致性边界实测 |

后三项是制作方向，不是现成可售商品。`ecommerce-main-image` 也不能因已有模板就标为已验收。

### 场景套装

- **Creator Launch Kit，候选 $19/¥99：** 图文轮播 + 公众号头图 + 产品发布海报。三个付费组件全部可售后再创建 SKU；免费封面可以作为配套链接，不能计入“付费价值”抬高划线价。
- **Shop Campaign Kit，候选 $29/¥149：** 电商主图 + 活动横幅 + 门店营销工作流。必须用同一商品/活动资料贯穿验证；不是把三个互不相干的包压成 ZIP。
- 套装是固定商品清单，不含未来所有商品；已包含的商品更新随对应商品提供。
- Pro 用户直接使用套装内已有自营 Skill，不另收打包费；可以另外销售明确区分的定制服务。
- 重复购买时识别已有商品并给出差额或拒绝重复收费。首版未实现差价能力时明确提示，不能静默按全价再卖。

### 升级规则

首期采用简单路径：单品页同时显示单次价与 Pro 价；已有会员显示“已包含”。不把未经实现的自动抵扣作为宣传权益。

后续可测试“购买单品后 7 天内升级年付，抵扣一笔符合条件的实付单品金额，最高 $19/¥99”。规则需绑定订单、同账号/币种、不可重复、退款联动；先完成后台幂等与退款处理，再公开承诺。此项是实验候选，不是首发必需。

## 7. 商品销售页规范与宣传素材

商品页顺序：

1. 首屏展示真实输出、任务名、单品价及会员包含状态。
2. 24–30 秒英文 16:9 功能演示：输入资料 → 关键运行/编辑过程 → 导出成品 → 下一步入口，无口播。
3. 明确交付文件、可编辑范围、所需输入、适合与不适合的任务。
4. 列出已测试 Agent/版本/系统、模型账号、额外成本和最近验证日期。
5. 展示安装提示词、CLI、ZIP 中已真实可用的渠道，附一个最小可运行示例。
6. 解释单品/会员的有效期、商用、到期后使用、支持和退款。

内容制作继续使用自媒体工作流与 huashu-motion；需要合成图片时使用 Codex 生图并保留来源、提示词、输出与权利记录。包装工具不自动成为被售包的组成部分；若分发上游代码或素材，单独核对许可证与归属。

六条已有宣传片作为素材基础，不能替代独立 Agent 安装和商品许可验收。模拟案例、HTML 重建界面、后期配乐等在案例说明中明确；不伪装客户订单、营收或真实操作录屏。

**脱敏发布门槛：** 安装包、examples、截图、视频画面、字幕、文件元数据和公开日志均检查；去除凭证、个人目录、私人邮件、账号 ID、客户资料与内部 URL。优先使用原创虚构品牌和 `example.com`，而非对真实客户姓名简单替换。

## 8. 取消、退款与支持政策草案

以下为商业处理建议，发布前需要与结账告知、正式条款和实际服务能力统一，不能替换已购用户合同。

- 自动续费渠道：取消停止下一期扣款，已付期内保留访问。预付渠道：显示具体到期日和是否需要手动续费，不写虚假的自动续费或取消入口。
- 平台未交付访问、重复收费、被确认的未授权扣款：提供核查与纠正流程，不用“不退款”一概排除。
- 在明确支持环境中存在阻断使用的可复现问题：建议购买后 7 日内可提交，先修复；承诺的处理窗口内无法恢复则退款。支持窗口需按真实人力确定后再公开。
- 已获访问后的单纯不使用、主观风格偏好，不默认提供按剩余天数比例退款；购买前充分展示样本和限制，并保留适用的法定权利。
- 创作台任务失败返还积分与 Skill 商品退款是不同流程，分别说明。
- 安装支持不包含代做项目或无限改稿；首期不宣传 24/7、固定响应 SLA 或专属顾问。

## 9. 增长与经济模型

先用自有功能演示与教程引流到具体商品，不把全部链接导向泛首页。每条内容保留 `utm_source`、`utm_medium`、`utm_campaign`、`utm_content` 与 Skill slug；在支付服务端记录归因，浏览器点击不算成交。

建议验证指标，均非当前实测：

| 环节 | 事件 / 口径 |
| --- | --- |
| 商品兴趣 | 唯一详情访问、演示播放完成；按商品和渠道拆分 |
| 激活 | 安装成功 + 用户自愿反馈的首次有效输出；不上传私有输入/输出全文 |
| 购买 | 服务端支付成功订单去重；与仅 checkout_started 区分 |
| 留存 | 第 30 日仍有有效访问且再次使用/更新；按购买周期分组 |
| 售后 | 每百订单支持工时、阻断缺陷率、退款率、取消原因 |
| 内容效率 | 各 Skill 带来的单品收入、会员升级与维护工时 |

首期不同时开高佣金分销。获得真实成本后可试行 **20% 净实收、首购起 12 个月内合资格订阅付款**，退款/拒付冲回，Lifetime 暂不参与；这是建议试点规则，尚未实现或对外开放。

贡献毛利公式：

`不含代收税的实收 − 支付手续费 − 退款/拒付 − 渠道佣金 − 存储分发 − 可归属支持维护 − 平台承担的模型费用`

示例仅作压力测试：$79 年付，假设手续费 3% + $0.30、佣金 20%、每年可归属维护分发支持 $12，则剩 $48.53；若佣金 40%，剩 $32.73。两者均未扣固定研发成本，不代表利润。若再承担 $5/月算力，一年多支出 $60，两种情形均转负。实际费率、税费、退款和支持成本需实测。

内容会员能被用户订一个月后下载已开放商品，这是允许保留已获版本的自然结果。靠持续新增、可复现质量和维护支持促成续费，不用远程锁死已下载文件维持续费。

下载公平使用建议首期 20 个不同付费 Skill/账号/UTC 日，网站与 CLI 共用；重复下载同一 Skill 不重复计数，失败不计，正常版本更新可豁免。此规则尚未实现，不得先写成正在执行；限额保护分发，不承诺阻止复制。

## 10. 实施顺序与验收

| 阶段 | 必须完成 | 完成证据 |
| --- | --- | --- |
| P0 内容就绪 | 免费五项、首个付费商品；脱敏、逐包许可证与依赖、干净环境安装、真实案例 | 包版本、哈希、测试环境、输入输出、许可清单；英文支持单独验收 |
| P1 交易基础 | 内容权益与算力拆分；保护历史订阅；单品订单与履约/退款；旧 Pro/Max 不重复收费 | 服务端 SKU/币种一致、支付幂等、重复 webhook、退款、到期与权益并存验证 |
| P1 订阅上线 | 至少五个付费商品可售；月/年相同内容权益；取消与账期说明；更新中英条款及页面 | 桌面/手机详情→安装→支付→下载→取消/到期流程；真实环境验收单独记录 |
| P2 扩展 | 固定套装、差价、Founding Lifetime 名额与管理、渠道分销 | 对应订单与退款覆盖，维护周期和实际经济模型成立 |
| 后续 | Team、第三方 Marketplace、分账、网页运行 | 独立设计与验收；不作为当前会员隐含权益 |

工程重点：
