# WebToMind 品牌与 Skill 官网迭代

日期：2026-10-21。基于 oil-ui 0.23.8；适用“存量项目优化 UI”路径，保留已确定的品牌资产与业务结构，从源头调整布局。用户要求迭代现有官网而非另选品牌，因此直接完成一个方向，不重复要求方向批准。

## 设计北极星

让用户看到：WebToMind 能把自己的 Agent 变成一间可复用的创作工作室，交付具体、可编辑的作品。

核心人群是有内容、品牌、提案和产品展示任务的创作者与小团队。首页负责品牌解释和引导发现；目录负责快速选择，详情负责判断输出、依赖与购买。品牌不是“售卖图片”，也不是“又一个聊天框”。

## 基线与参考

真实截图保存在 `output/oil-ui-brand/references/`；此前首页与详情基线在 `output/oil-ui-brand/baseline/`。

- [Skillry](https://skillry.dev/)：深底与高亮会员横条形成强对比；首页以居中大字、图标行和少量主动作介绍 Agent Skills；圆形或胶囊控件突出动作；兼容 Agent 在主动作后出现。沿用“能力→示例→安装”的顺序，改用自己的实际产出而不是图标墙，不复刻黑黄配色、文字投影或商品素材。
- [YouMind Skills](https://youmind.com/zh-CN/skills)：白底衬线大标题，精选文章/创作者卡与编辑精选建立内容入口；列表的作品缩略图承担识别；浏览入口多、密度较高。沿用内容优先与分类浏览；现阶段不复制创作者排行榜、用户头像或奖励故事。
- 旧首页左文右图、多个搜索/浏览动作同时争夺首屏，主视觉是三张静态叠图。此次把首屏变成通栏品牌标题与可切换作品展台，搜索移到正式发现区。

## 方向卡

| 项目 | 决定 |
| --- | --- |
| 调性 | 中等能量、精确对齐、首屏疏而商品区适度密；重标题、轻边框；友好但不玩具化。创作者需要想象空间，也需要可核验的交付。 |
| 引擎 | 真实的创作工作台：输入简报→作品→可带走的源文件。它来自 Skill 处理的任务本身。 |
| 首屏骨架 | 通栏两行大字；短介绍与两个层级的动作；下方交互作品展台。避免旧版左右“口号＋装饰图”构图。 |
| 字体 | 沿用 Geist Sans 与既有中文回退；桌面展示字最高 80px、正文 18px，手机展示字 36–56px、正文 16px。安装命令和步骤编号保留既有等宽字体。 |
| 色彩 | 既有陶土品牌色 #943c27 为强调/主动作；#faf9f6 为画布；#25221f 为墨色；#efddd0 为作品展台底色；#fffaf6 为选中底，#d5bba9 为展台描边。来自既有品牌变量与实际演示作品的温暖纸面。 |
| 主视觉 | 复用已脱敏的案例 Deck、分享图、网页与功能视频实际输出；未新增生成素材或竞品素材。 |
| 控件 | 10px 圆角主按钮、固定尺寸的类型切换、清晰文字链接；箭头表示导航。保留现有菜单、搜索、视频和购买行为。 |
| 记忆点 | 切换图文/演示/网页/视频，同一展台立即换成对应简报、作品和交付格式；“看功能演示”原地播放真实视频。 |
| 结构延展 | 首页发现区、视频货架、使用步骤、安装、价格、FAQ；目录/详情/价格共享画布、按钮、卡片和选中态。旧创作台和提示词保持工具属性。 |
| 放弃 | 重复眉标、英雄区搜索框、装饰性拼贴、无来源指标与评价、大面积渐变光晕。 |

与标杆的差异：Skillry 为黑底图标墙，YouMind 为白底内容门户；WebToMind 用既有陶土色、Geist 通栏标题与真实输入/输出展台，保留商品发现的通用结构但不复刻视觉身份。

## 动效与可访问性

沿用项目已安装的 Motion，不新增动效依赖。首次进入标题与说明一起短距离出现（0.5 秒），类型切换使结果轻移淡入（0.22 秒），货架滚入时一次性落位；按钮沿用项目既有按下反馈。展台输出在滚动中从 0.86 放大到 1，表达从简报走近成品，不锁定页面或接管滚动。正文、导航、按钮不随滚动缩放。

减少动态效果时，全部信息静态呈现，卡片保留用户主动播放。英雄区视频仅在点击后加载，切换作品会卸载视频，离屏/后台暂停。手机保留分类、成品、演示按钮和商品详情入口，减少重复解释；四类演示均为英文、16:9、无口播。

开发预览 `http://127.0.0.1:4203/en-US/overview`，通过 `scripts/preview-skill-design.mjs` 读取当前源码，复用本机只读候选 API。候选商品与价格不等于生产上架；未执行生产写入或部署。

证据、对比、视口截图、录屏与检查记录在 `output/oil-ui-brand/`，入口为 `output/oil-ui-brand/review.html`。

### 本地验收

- Node 24.14.0：`pnpm type-check`、针对首页和新英雄区的 ESLint、`git diff --check` 通过。按 oil-ui 规定，本轮没有运行生产构建或全量测试。
- 既有目录脚本：6 组通过，覆盖英文/中文 × 1440/390/360px，搜索、任务/价格筛选、移动菜单、错误重试与空态。
- 新品牌页脚本：9 组通过，覆盖英文/中文 × 1440/768/390/360px；4 类作品与对应静音视频、切换卸载、商品详情跳转、月付切换、无横向溢出、无页面错误、未交互前不请求视频，以及减少动态效果、键盘切换和 200% 缩放等效 CSS 视口（720px）。等效视口检查不冒充真实浏览器菜单缩放操作。
- 既有视频/详情脚本：每轮 7 组，连续 3 轮通过。桌面悬停、手动暂停/恢复、离开暂停；触屏主动播放、滚出暂停；10 个视频可解码；详情切换、复制和失败恢复均由原脚本覆盖。
- 先前视频检查偶发失败由测试点击的再次自动滚动造成：滚动让指针离开卡片，暂停后按钮变回播放。验证事件序列后改为在已悬停位置直接按下/松开鼠标，不改变产品播放逻辑，也不删除暂停断言。
- oil-ui 截图工具对桌面和手机检查没有控制台错误、横向溢出、损坏图片或可读性警告。剩余两项嵌套提示保留：16:9 输出画框属于作品展台；命令框属于安装区，是可复制的操作对象。
- 已实际查看桌面完整页、手机首页/详情/定价、暗色页面与放大布局。入场/切换/整页滚动有录屏及帧序列；已核对帧与交互状态，未将其表述为人工按正常速度观看录屏的动效验收。

### 一轮独立评审及处理

采用 oil-ui 的“存量已有界面润色评审”，隔离评审者只看截图与页面，不打分。原始报告：`output/oil-ui-brand/independent-review.md`。

1. 月付价格与 Yearly 高亮的截图矛盾：DOM 状态正确，旧截图早于颜色过渡完成。采集改为等待动画完成，并断言当前选项最终背景色，稳定截图中 Monthly 与 $9.99/month 一致。
2. 手机详情的产品身份出现过晚：媒体之后先展示名称、用途与获取状态，Agent 兼容信息后置；桌面仍为左右两列。
3. 分类近似双高亮：选中保留实底，未选中悬停改为文字下划线，保留键盘焦点环；触屏不会残留第二个选中色块。
4. 中文窄屏断行：压缩主说明并保留可复用、自己的 Agent、可编辑三项价值。源码已核实为全角中文标点；截图中字体的标点形态不作为半角字符的证据。

另外检查暗色显示后，将浅陶土按钮与选中项改用深色文字，保持阅读对比度。

### 减法与边界

移除英雄区内的搜索、重复眉标和静态装饰叠图，搜索集中在发现区；手机展台省去桌面已表达的结果标题与重复解释，保留真实作品、交付格式、视频与详情入口。减轻主按钮投影和卡片边框，没有新增指标、用户评价或第三方作品。

预览启动脚本仅在本地预先关闭既有语言提示与 Google 登录备用提示，便于检视画面；未修改生产认证或弹窗逻辑。商品来自本地候选 API，购买写入不可用，测试不能证明线上商品已上架或真实支付成功。没有运行 CI、部署、数据库迁移、素材公开发布或真实结账；生产验收不在本轮范围内。


## 官网落地页入口确认（2026-10-21）

用户确认此版本作为官网落地页。现有 React 根路由与 Worker 根域名跳转均进入本地化 `SkillHomePage`：英文 `/en-US/overview`，中文 `/zh-CN/overview`；按已有语言偏好/浏览器语言选择，无法识别时英文优先。Logo 返回相同页面，旧图片/提示词入口保留为次级工具。

补齐两处：中英文短路径跳转使用保留 query/hash 的公共组件，避免丢失落地推广参数；首页服务器 SEO 正文改为品牌主张与 Skill 目录、免费 Skill、会员定价入口，移除首页回退正文中的旧 Prompt 主入口。其他工具页的 SEO 正文保持原样。

本地验证：105 项针对性路由/SEO/语言守卫测试通过；浏览器检查 12 个入口组合（根路径、语言短路径、overview × 中英文 × 桌面/手机）与 4 次 Logo 返回，UTM/hash 均保留。证据在 `output/oil-ui-brand/landing-entry/`；测试日志 `landing-tests.log`。这次确认与修改未触发生产部署。
