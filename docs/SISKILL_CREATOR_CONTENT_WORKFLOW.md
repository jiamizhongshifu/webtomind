# Creator Content Workflow

Original SiSkill editorial Skill, version 1.0.0. US$9.99 single purchase; included in
SiSkill Pro alongside Customer Case Study Deck and NotebookLM Video. Account,
checkout, refund and membership isolation use the existing SiSkill commerce path.
No new schema or billing provider is introduced.

## Delivery and boundaries

Topic framing, source ledger, full master draft, fact review, a 115-point editorial
rubric, independently reviewed selected platform drafts, visual/video briefs,
local HTML review page and retrospective template. The package supports English
and Chinese; the bundled original fictional example contains an English master,
an X thread and a Chinese Xiaohongshu note. The examples are actually authored,
reviewed and exported, not customer results or performance evidence.

The Agent writes and judges. The dependency-free Node.js 22+ helper validates
source-extract references and revision-bound reviews, exports Markdown/HTML/JSON,
refuses existing output directories and separates prepared/reviewed from published.
It does not independently verify truth, generate images/videos, collect analytics
or publish to social platforms. The buyer supplies model access and optional
research/media/publishing tools; their costs are separate. These limits appear on
the detail page and immediately before purchase.

Private source, templates and full example ship only in the authenticated paid
archive. They do not enter this public repository. The archive is deterministic,
privacy-scanned and hash-pinned in `apps/siskill/paid-releases.json`; private R2
readback and extracted execution are verified before activation. Public assets are
sanitized demonstration derivatives. No personal identity, writing corpus, private
account settings, customer material or third-party Skill implementation is included.

## Verification scope

Fourteen package checks cover changed source/text invalidation, independent variant
reviews, unsupported extracts, blockers, score range/threshold, filename traversal,
reserved names, output preservation, escaped HTML, hash integrity and symlink paths.
The archive is exercised in both Codex and Claude project directory layouts; this
is not a claim of automatic discovery or a second independent Agent writing run.

The store demo uses huashu-motion with the existing licensed font/runtime assets:
24 seconds, English, 16:9, silent. Scenes 1–3 visualize actual example content; the
last scene shows the actual local review output. Visual plans remain explicitly
plans. The promotional runtime is not included in the paid package. See public
media provenance for hashes and technical checks.

Production acceptance requires the exact CI-checked commit, both locale routes,
Writing filter/search, desktop/mobile detail and gallery, muted card autoplay,
sign-in requirement, offer amount and Pro inclusion, plus private download denial
for unauthenticated and unentitled users. A hosted live-mode Checkout inspection
without submitting payment is not a completed real-money purchase. Preserve that
boundary in the final release report.
